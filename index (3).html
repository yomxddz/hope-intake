🔥 One-time Firebase Setup

This tool needs a free Firebase database so all your coordinators see the same live data. Takes 3 minutes.

1
Go to console.firebase.google.com and sign in with Google
2
Click Create a project → name it "hope-intake" → click through (disable Analytics is fine) → Create
3
In the left sidebar click Build → Realtime Database → Create database → Start in test mode → Enable
4
Copy the database URL shown (looks like https://hope-intake-xxxxx-default-rtdb.firebaseio.com) and paste it below
